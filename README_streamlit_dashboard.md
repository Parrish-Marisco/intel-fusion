# Hybrid Intelligence Analysis Platform - Streamlit Dashboard

## Run locally

```bash
pip install streamlit pandas matplotlib networkx
streamlit run streamlit_app.py
```

## Input file

Place `unified_graph.json` in the same directory, or upload it in the sidebar.

## What it shows

- Top entities by threat score
- Entity type distribution
- Entity explorer with relationship map
- Location hotspot ranking
- Raw nodes and edges tables
